Система пользователей и ролей

В АИС "Компьютерный салон" реализована система разграничения прав доступа на основе ролей пользователей.

👑 Администратор

Полный доступ ко всем функциям системы, управление пользователями.

👨‍💼 Менеджер

Доступ к управлению товарами, поставщиками, приходом и расходом.

📦 Кладовщик

Доступ к учету товаров, приходным операциям.

💰 Кассир

Доступ только к оформлению продаж и расходным операциям.

Учетные записи по умолчанию

При первом запуске система создает учетную запись администратора:

Учетные данные по умолчанию:
Логин: admin
Пароль: admin
Важно! Рекомендуется немедленно сменить пароль администратора после первого входа в систему.

Добавление нового пользователя

Шаг 1:

Войдите в систему под учетной записью администратора.

Шаг 2:

Перейдите в раздел управления пользователями (в текущей версии доступно через прямое редактирование базы данных).

Шаг 3:

Для добавления пользователя через базу данных выполните SQL-запрос:

INSERT INTO users (username, password, role, full_name) 
VALUES ('username', 'password', 'role', 'Полное имя');
Шаг 4:

Доступные роли: admin, manager, storekeeper, cashier

Смена пароля

Шаг 1:

Войдите в систему под своей учетной записью.

Шаг 2:

Для смены пароля выполните SQL-запрос:

UPDATE users SET password = 'новый_пароль' WHERE username = 'ваш_логин';
Рекомендация: Используйте сложные пароли, содержащие буквы, цифры и специальные символы.

Безопасность пользователей

Рекомендации по безопасности:

  • Используйте уникальные логины для каждого пользователя
  • Регулярно меняйте пароли
  • Не используйте простые пароли (qwerty, 123456 и т.д.)
  • Предоставляйте минимально необходимые права доступа
  • Регулярно проверяйте список активных пользователей
  • Удаляйте учетные записи уволенных сотрудников
