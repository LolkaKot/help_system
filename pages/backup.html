Система резервного копирования

Модуль резервного копирования обеспечивает сохранность данных и возможность восстановления информации в случае сбоев, ошибок или повреждения базы данных.

💾 Создание копий

Автоматическое и ручное создание резервных копий базы данных.

🔄 Восстановление

Быстрое восстановление данных из резервной копии.

📅 Автоматизация

Настройка автоматического резервного копирования по расписанию.

🔐 Безопасность

Шифрование резервных копий и защита от несанкционированного доступа.

Создание резервной копии

Шаг 1:

Перейдите в раздел "Резервное копирование" через боковую панель навигации.

Шаг 2:

Нажмите кнопку "Создать резервную копию".

Шаг 3:

Выберите тип резервной копии:

  • Полная копия - вся база данных
  • Только данные - без структуры таблиц
  • Выборочная - определенные таблицы
Шаг 4:

Укажите место сохранения файла резервной копии.

Шаг 5:

Нажмите "Создать копию".

Примечание: Резервные копии сохраняются в формате SQL для обеспечения совместимости.

Восстановление из резервной копии

Внимание! Восстановление из резервной копии приведет к потере всех данных, созданных после даты создания копии.
Шаг 1:

Перейдите в раздел "Резервное копирование".

Шаг 2:

Нажмите кнопку "Восстановить из копии".

Шаг 3:

Выберите файл резервной копии для восстановления.

Шаг 4:

Подтвердите начало процесса восстановления.

Шаг 5:

Дождитесь завершения процесса и перезапустите программу.

Автоматическое резервное копирование

Настройка расписания:

  • Ежедневно - в указанное время
  • Еженедельно - в определенный день недели
  • Ежемесячно - в указанный день месяца
  • При запуске программы - создание копии перед началом работы

Параметры автоматического копирования:

  • Количество хранимых копий - автоматическое удаление старых копий
  • Путь сохранения - локальная папка или сетевой ресурс
  • Уведомления - оповещения об успешном/неуспешном копировании

Управление резервными копиями

Просмотр списка копий:

  • Дата и время создания
  • Размер файла
  • Тип копии
  • Версия программы
  • Статус целостности

Операции с копиями:

  • Просмотр информации - детали резервной копии
  • Проверка целостности - проверка на ошибки
  • Удаление - удаление ненужных копий
  • Экспорт - сохранение копии в другое место

Рекомендации по резервному копированию

Частота копирования:

  • Ежедневно - для активных систем с большим объемом данных
  • Еженедельно - для систем со средним объемом операций
  • Перед обновлением - всегда создавайте копию перед обновлением программы

Хранение копий:

  • Храните копии на отдельном физическом носителе
  • Используйте облачные хранилища для важных данных
  • Регулярно проверяйте целостность старых копий
  • Ведите журнал операций резервного копирования

Правило 3-2-1:

  • 3 копии данных
  • 2 разных типа носителей
  • 1 копия в удаленном хранилище

Восстановление после сбоев

Типичные сценарии:

Повреждение базы данных:

Действия:

Восстановите из последней резервной копии и выполните операции, пропущенные с момента создания копии.

Ошибочное удаление данных:

Действия:

Восстановите из копии, созданной до момента ошибки.

Аппаратный сбой:

Действия:

Установите программу на новый компьютер и восстановите данные из резервной копии.

Решение часто задаваемых вопросов

Проблема: Недостаточно места для резервной копии

Решение: Освободите место на диске или измените путь сохранения копий.

Проблема: Ошибка при создании копии

Решение: Убедитесь, что база данных не заблокирована другими процессами.

Проблема: Восстановление не завершается

Решение: Проверьте целостность файла резервной копии и наличие прав доступа.
