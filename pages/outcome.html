Расходные операции

Модуль учета расхода товаров предназначен для оформления продаж, списания товаров и формирования расходных накладных. Система автоматически уменьшает складские остатки при проведении расходных операций.

Создание расходной накладной

Шаг 1:

Перейдите в раздел "Расход" через боковую панель навигации.

Шаг 2:

Нажмите кнопку "Создать расходную накладную".

Шаг 3:

Заполните общую информацию:

  • Номер накладной - уникальный идентификатор
  • Клиент - ФИО или название организации
  • Дата накладной - дата продажи
Шаг 4:

Добавьте товары в накладную:

  • Выберите товар из справочника
  • Укажите количество (проверяется доступность)
  • Введите цену продажи
  • Нажмите "Добавить в накладную"
Шаг 5:

Проверьте правильность данных и общую сумму.

Шаг 6:

Нажмите кнопку "Сохранить накладную".

Контроль остатков при продаже

Важно! Система не позволяет продать больше товара, чем есть в наличии на складе.

Процесс контроля:

  • При добавлении товара проверяется текущий остаток
  • Если количество превышает остаток - выводится предупреждение
  • Накладная не может быть сохранена при недостатке товара
  • После сохранения накладной остатки автоматически уменьшаются

Учет клиентов

При создании расходной накладной можно указать информацию о клиенте:

  • Физическое лицо - ФИО покупателя
  • Юридическое лицо - название организации
  • Контактные данные - телефон, email (опционально)
Примечание: В текущей версии система не ведет отдельную базу клиентов, информация сохраняется только в накладной.

Цены продажи

Настройка цен:

  • Цены по умолчанию берутся из карточки товара
  • Возможность ручной корректировки цены при продаже
  • Фиксация фактической цены продажи в накладной
  • История изменения цен для анализа
Рекомендация: Регулярно обновляйте цены в карточках товаров для корректной работы системы.

Просмотр истории продаж

Шаг 1:

Перейдите в раздел "Расход".

Шаг 2:

Система отобразит список всех расходных накладных.

Шаг 3:

Для просмотра деталей нажмите на соответствующую строку.

Шаг 4:

Используйте фильтры для поиска по дате, клиенту или номеру.

Отмена продаж

Шаг 1:

В списке накладных найдите нужный документ.

Шаг 2:

Нажмите кнопку "Аннулировать".

Шаг 3:

Подтвердите отмену накладной.

Шаг 4:

Система автоматически вернет товары на склад.

Внимание! Отмена продажи возможна только для накладных текущего дня. Для более старых накладных создавайте возвратные накладные.

Решение часто задаваемых вопросов

Проблема: Недостаточно товара на складе

Решение: Уменьшите количество в накладной или дождитесь поступления товара от поставщика.

Проблема: Цена продажи не соответствует карточке товара

Решение: Проверьте актуальность цен в справочнике товаров. При необходимости скорректируйте цену вручную.

Проблема: Ошибка при сохранении накладной

Решение: Убедитесь, что заполнены все обязательные поля и добавлена хотя бы одна позиция товара.
