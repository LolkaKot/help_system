Добавление нового поставщика

Шаг 1:

Перейдите в раздел "Поставщики" через боковую панель навигации.

Шаг 2:

Нажмите кнопку "Добавить поставщика".

Шаг 3:

Заполните форму данными поставщика:

  • Название* - официальное наименование компании
  • Контактное лицо - ФИО ответственного менеджера
  • Телефон - контактный телефон
  • Email - электронная почта
  • Адрес - юридический или фактический адрес
Шаг 4:

Нажмите кнопку "Сохранить".

Примечание: Поле "Название" является обязательным для заполнения.

Редактирование информации о поставщике

Шаг 1:

В списке поставщиков найдите нужную компанию.

Шаг 2:

Нажмите кнопку "Редактировать" (иконка карандаша) в строке поставщика.

Шаг 3:

Внесите необходимые изменения в форму.

Шаг 4:

Нажмите кнопку "Сохранить".

Удаление поставщика

Внимание! Удаление поставщика невозможно, если с ним связаны приходные накладные. В таких случаях рекомендуется отметить поставщика как неактивного.
Шаг 1:

В списке поставщиков найдите компанию для удаления.

Шаг 2:

Нажмите кнопку "Удалить" (иконка корзины).

Шаг 3:

Подтвердите удаление в диалоговом окне.

Поиск и фильтрация поставщиков

Поиск по названию:

Используйте поле поиска для быстрого нахождения поставщика по названию компании.

Фильтрация по активности:

В текущей версии фильтрация доступна через прямое редактирование базы данных.

Сортировка:

Поставщики автоматически сортируются по названию компании в алфавитном порядке.

История сотрудничества

Для каждого поставщика система автоматически ведет историю приходных накладных:

  • Общее количество поставок
  • Суммарный объем поставок
  • Дата последней поставки
  • Средняя периодичность поставок
Примечание: Подробная аналитика по поставщикам доступна в разделе "Отчеты".

Рекомендации по ведению базы поставщиков

Качество данных:

  • Регулярно обновляйте контактную информацию
  • Указывайте актуальные телефоны и email
  • Добавляйте полные юридические наименования
  • Ведите историю смены контактных лиц

Организация работы:

  • Группируйте поставщиков по категориям товаров
  • Отмечайте основных и резервных поставщиков
  • Ведите рейтинг надежности поставщиков
  • Регулярно проводите сверку данных

Экспорт данных о поставщиках

В текущей версии экспорт данных доступен через:

  • Прямой доступ к базе данных SQLite
  • Использование SQL-запросов для выгрузки
  • Ручное копирование данных из интерфейса
Пример SQL-запроса для экспорта: 
SELECT * FROM suppliers ORDER BY name;
