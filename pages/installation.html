Подготовка к установке

Перед установкой АИС "Компьютерный салон" убедитесь, что на вашем компьютере установлен Python версии 3.8 или выше.

Шаг 1:

Проверьте установленную версию Python:

python --version
# или
python3 --version
Шаг 2:

Если Python не установлен, скачайте его с официального сайта:

https://www.python.org/downloads/

Установка системы

Шаг 1:

Скачайте архив с программой или склонируйте репозиторий.

Шаг 2:

Распакуйте архив в выбранную директорию.

Шаг 3:

Установите необходимые зависимости. Откройте командную строку в папке с программой и выполните:

pip install flet
Шаг 4:

Запустите программу:

python main.py
Примечание: На Windows может потребоваться использовать python вместо python3.

Первоначальная настройка

Шаг 1:

При первом запуске система автоматически создаст базу данных и таблицы.

Шаг 2:

Для входа в систему используйте учетные данные администратора по умолчанию:

  • Логин: admin
  • Пароль: admin
Важно! Сразу после первого входа смените пароль администратора для обеспечения безопасности.
Шаг 3:

Система автоматически создаст базовые категории товаров:

  • Компьютеры
  • Ноутбуки
  • Комплектующие
  • Периферия
  • Программное обеспечение

Структура файлов

После установки в рабочей директории будут созданы следующие файлы:

computer_store/
├── main.py              # Основной файл программы
├── computer_store.db    # База данных (создается автоматически)
├── requirements.txt     # Список зависимостей
└── backup/             # Папка для резервных копий (создается автоматически)

Решение проблем при установке

Проблема: Ошибка "ModuleNotFoundError"

Решение: Убедитесь, что все зависимости установлены правильно:

pip install flet sqlite3 datetime os json

Проблема: Ошибка доступа к базе данных

Решение: Проверьте права доступа к папке с программой. Запустите программу от имени администратора.

Проблема: Программа не запускается

Решение: Убедитесь, что используется корректная версия Python. Проверьте путь к интерпретатору.

Обновление системы

Для обновления системы до новой версии:

Шаг 1:

Создайте резервную копию базы данных.

Шаг 2:

Остановите работающую программу.

Шаг 3:

Замените файлы программы на новые версии.

Шаг 4:

Запустите программу. Система автоматически обновит структуру базы данных при необходимости.
