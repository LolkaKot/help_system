Проблемы запуска программы

Ошибка: "ModuleNotFoundError: No module named 'flet'"

Решение:

Установите необходимые зависимости:

pip install flet

Ошибка: "Python not found"

Решение:

Убедитесь, что Python установлен и добавлен в PATH:

python --version

Если команда не работает, переустановите Python с опцией "Add Python to PATH".

Ошибка: "Access is denied"

Решение:

Запустите программу от имени администратора или проверьте права доступа к папке с программой.

Проблемы авторизации

Ошибка: "Неверный логин или пароль"

Решение:

Используйте учетные данные по умолчанию:

  • Логин: admin
  • Пароль: admin

Если не помогло, проверьте базу данных напрямую:

sqlite3 computer_store.db
SELECT * FROM users;

Ошибка: "Нет прав доступа"

Решение:

Обратитесь к администратору системы для предоставления необходимых прав доступа.

Проблемы с базой данных

Ошибка: "database is locked"

Решение:

Закройте все экземпляры программы и перезапустите. Если проблема persists, перезагрузите компьютер.

Ошибка: "disk I/O error"

Решение:

Проверьте свободное место на диске. Если место есть, возможно повреждение базы данных - восстановите из резервной копии.

Ошибка: "no such table"

Решение:

Удалите файл computer_store.db и перезапустите программу. Система автоматически создаст новую базу данных с правильной структурой.

Проблемы с производительностью

Программа работает медленно

Решение:

Выполните следующие действия:

  • Закройте ненужные приложения
  • Увеличьте объем оперативной памяти
  • Проверьте компьютер на вирусы
  • Очистите временные файлы

Долгая загрузка данных

Решение:

Выполните оптимизацию базы данных:

sqlite3 computer_store.db "VACUUM;"

Проблемы с приходными и расходными накладными

Невозможно сохранить накладную

Решение:

Проверьте:

  • Заполнены все обязательные поля
  • Добавлена хотя бы одна позиция товара
  • Количество товара не превышает остаток (для расходных накладных)
  • Цены указаны корректно

Неверные остатки товаров

Решение:

Выполните пересчет остатков:

-- Создайте резервную копию перед выполнением
-- Обновите остатки на основе приходных и расходных накладных

Восстановление базы данных

Ручное восстановление

Шаг 1:

Создайте резервную копию поврежденной базы данных.

Шаг 2:

Попробуйте восстановить базу с помощью утилиты SQLite:

sqlite3 computer_store.db ".dump" | sqlite3 new_database.db
Шаг 3:

Если не помогло, восстановите из последней резервной копии.

Автоматическое восстановление

Действие:

Используйте функцию восстановления из раздела "Резервное копирование".

Журналирование ошибок

Для диагностики сложных проблем включите ведение журнала ошибок:

Включение логов:

Добавьте в код программы перед запуском:

import logging
logging.basicConfig(level=logging.DEBUG, 
                    format='%(asctime)s - %(levelname)s - %(message)s',
                    filename='app.log')
Анализ логов:

Проверьте файл app.log в папке с программой для получения подробной информации об ошибках.

Профилактика проблем

Регулярное обслуживание:

  • Создавайте резервные копии ежедневно
  • Проверяйте целостность базы данных раз в неделю
  • Обновляйте программу до последней версии
  • Очищайте временные файлы

Мониторинг системы:

  • Контролируйте свободное место на диске
  • Следите за использованием оперативной памяти
  • Проверяйте журналы ошибок
  • Тестируйте восстановление из резервных копий

Обращение в техническую поддержку

Если вы не смогли решить проблему самостоятельно, обратитесь в техническую поддержку.

Подготовьте следующую информацию:

  • Версия программы
  • Операционная система
  • Текст ошибки (скриншот или копия)
  • Действия, приводящие к ошибке
  • Файл логов (app.log)
